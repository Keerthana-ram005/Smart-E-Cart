# Smart eCart

## Overview

Smart eCart is an AI-assisted e-commerce prototype that aims to simplify grocery shopping from cooking videos. The system allows users to submit a YouTube recipe video URL, extracts relevant recipe information, and generates a list of ingredients that can be used for shopping purposes.

This project currently focuses on backend processing, database management, and YouTube URL analysis rather than a complete e-commerce platform.

## Features

### Implemented Features

* YouTube recipe video URL submission
* Backend processing of video information
* Ingredient extraction workflow
* Database integration for storing extracted data
* Simple user interface for URL input
* Data management and retrieval operations

### Planned Features

* Complete e-commerce product catalog
* Shopping cart functionality

## Project Workflow

1. User enters a YouTube recipe video URL.
2. The backend processes the video data.
3. Recipe ingredients are extracted from the available content.
4. Extracted ingredients are stored in the database.
5. The system returns the processed ingredient information.
